# Project Brief: ModularStep.com

## Goal
Build a modern, certified industrial climbing and access systems configurator (ModularStep) for Teknosis Havacılık ve Savunma A.Ş. The site includes a 3D WebGL configurator, full B2B catalog sections, compliance guides, and a password-protected admin panel with an SQLite backend.

## Success Criteria
- Fully functional multi-page website (Products, About Us, Compliance, Contact, Admin).
- Interactive 3D WebGL (Three.js) configurator rendering stair crossovers.
- Admin portal to add, edit, and delete configurator presets.
- Persistent SQLite database on the VCN server.
- Reverse proxy API handling in Nginx.
- Deployment pipeline to Paris VCN and GitOps push to GitHub.
